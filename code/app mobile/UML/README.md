# Mobile App UML

This folder contains PlantUML source files for the mobile PWA.

Rules:

- Commit `.puml` source files.
- Keep at least one UML use-case diagram for the v1 app workflow.
- Update diagrams manually when app use cases, user-facing flows, Supabase behavior, or status display behavior changes.
- Do not regenerate diagrams automatically during normal app builds or dev-server runs.
- Generated image exports such as `.png` or `.svg` are optional local review artifacts; the `.puml` files are the source of truth.
